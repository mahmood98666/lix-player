# Contributing to Lix Player

First off, thank you for considering contributing to **Lix Player**! It's people like you that make open-source such an amazing place to learn, inspire, and create.

## Code of Conduct

This project and everyone participating in it is governed by the Code of Conduct. By participating, you are expected to uphold this code.

## How Can I Contribute?

### Reporting Bugs
- Ensure the bug was not already reported by searching on GitHub under Issues.
- Submit a detailed issue report with reproducible steps, device information (Android/iOS version), and Expo SDK version.

### Suggesting Enhancements
- Open an Issue with tag `[Feature Request]`.
- Provide a clear and concise description of what the enhancement achieves.

### Pull Requests
1. Clone the repo:
   ```bash
   git clone https://github.com/Mahmood/lix-player.git
   cd lix-player
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create your feature branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```
4. Build and test changes:
   ```bash
   npm run build
   ```
5. Commit and push:
   ```bash
   git commit -m 'feat: add amazing gesture control'
   git push origin feature/my-new-feature
   ```
6. Open a Pull Request on GitHub.

Thank you for your contributions!
